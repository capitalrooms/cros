Putting it into Gmail

  1. Press Copy on the signature.
  2. Gmail → cog → See all settings → General → Signature → Create new (call it “Reply picture”), and paste.
  3. Under Signature defaults, set On reply/forward use to “Reply picture”.
  4. Scroll down and press Save changes.
