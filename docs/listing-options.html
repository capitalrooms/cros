Room listings: three ways to build them

One listing per room or single let, written once in CROS and sent everywhere: the share link, the Capital Rooms website, and later Rightmove, Zoopla, OnTheMarket and SpareRoom. Looks come later, once the website design is set. This page is about structure and workflow.

The same in every option

The foundation: one listing record, shaped like a portal feed

Portals accept listings through data feeds with fixed fields. If CROS stores a listing in that shape from day one, sending it to Rightmove later is a connection job, not a rebuild. Rightmove's Real Time Datafeed (v1.4.1) now carries the Trading Standards "material information" fields too, so the same record covers the law.

Part A (rent, deposit, council tax) must be on every lettings listing; Parts B and C must be no more than one click away. Every option below checks Part A before a listing can go live.

Three options

Option A

Listing tabs on the room

The way Reapit and Alto do it. The listing lives on the room or unit, as a set of tabs: write the details, order the media, fill the material information, switch channels on, then preview each place it appears.

Option C

A marketing board

Every room coming free is a card moving across a board: Draft, Ready, Live, Let agreed. A card can only move to Ready when Part A is complete, and to Live when at least one channel is on. Let agreed withdraws it from every channel automatically. The editor (A or B) opens from the card.

Getting to the portals

What sending to Rightmove takes

  • A Rightmove lettings branch account (paid membership) and their Real Time Datafeed set up for that branch.
  • Each listing sent as one record; photos and floor plans by link; updates and withdrawals sent the same way.
  • Zoopla and OnTheMarket take similar feeds. SpareRoom and OpenRent suit room-by-room lets and can be added as channels.
  • Whether Rightmove takes individual rooms in a house share as separate listings should be confirmed with them when the feed is set up.
The website

Website preview and publishing

  • The website reads live listings from CROS, so a room switched on appears on the site without copying.
  • The share link already built becomes the phone version of the same page.
  • The look is decided with the website design. The listing record does not change when the look does.
Suggested

Build the foundation now, then B for editing and C for the pipeline

The listing record is the same whichever option you pick, so it can start straight away. B (side-by-side) gives the quickest route to good adverts and shows the website design the moment it exists. C (the board) can follow when there are more rooms to manage. A is the safest if you'd rather match what other agency software looks like.
